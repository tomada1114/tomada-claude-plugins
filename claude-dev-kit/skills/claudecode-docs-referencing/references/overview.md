# Claude Codeとは

## 概要

Claude Codeは、Anthropic社が開発した**CLIベースのAIコーディングエージェント**です。2025年にリリースされ、ターミナル上で動作するため、VS Code、JetBrains、その他のエディタなど、様々な環境と組み合わせて使用できます。

「〇〇を作って」「このバグを直して」といった自然言語の指示だけで、コードを書いたり編集したりできます。さらに、ファイルの読み書きやシェルコマンドの実行まで自律的に行うため、開発者は細かい操作から解放されます。

Claude Codeの登場は、**AI支援開発からAI駆動開発への転換**を象徴しています。人間がAIを補助的に使うのではなく、AIがタスク全体を主導して人間がレビューするという新しい開発スタイルです。

## 主要な5つの能力

### 1. コード生成

自然言語で「〇〇を作って」と指示するだけで実装を行います。複雑なアプリケーションの場合は技術選定について質問してくることもあり、対話的に進められます。

### 2. ファイル操作

- **Read** - ファイルを読む
- **Write** - ファイルを新規作成
- **Edit** - ファイルを編集

Claudeが自律的に実行するため、人間がファイルを開いて編集する必要はありません。既存のコードベースを読み込んで理解した上で、適切な場所に適切な変更を加えます。

### 3. Git連携

ブランチ作成、コミット、プルリクエスト作成まで一貫して実行可能です。

例：「このIssueを実装してPRを作成して」と指示すれば、実装からPR作成までの一連の作業を自動化できます。

### 4. 外部ツール連携（MCP）

**MCP (Model Context Protocol)** を通じて、データベース、Notion、GitHub Issues等の外部サービスと接続できます。これにより、Claude Codeの活用範囲は大幅に広がります。

### 5. Bash実行

シェルコマンドを直接実行し、ビルド・テスト・デプロイまで自動化できます。

- 「ReactでTodoアプリを作って」といった指示も可能
- テストを実行して失敗したら修正する、といった連続操作も可能
- 破壊的なコマンドを実行する前には確認を求めてくるため安全

## エージェント型の特徴

### 従来のAI支援ツールとの違い

| 特徴 | 従来のAI支援ツール | Claude Code（エージェント型） |
|------|-------------------|------------------------------|
| 主な機能 | コード補完 | タスク全体の委任 |
| 主導権 | 人間 | AI |
| 役割 | 補助的 | 自律的 |
| 動作方式 | コードを書いてくれる | タスクを完遂してくれる |

### エージェントループ

Claude Codeは以下のループを自律的に実行します：

1. ファイルを読んでコードを理解する
2. 計画を立てる
3. 実装する
4. テストを実行する
5. 必要に応じて修正する

人間は指示を出して結果を確認すれば良い、という開発スタイルが実現します。

### 質問による意図確認

Claude Codeは必要に応じて質問を投げかけてきます。これは**ユーザーの意図を正確に理解するため**です。

例：「認証機能を追加して」と指示した場合
- 認証方式は何を使いますか？（JWT、セッション、OAuth）
- ユーザー情報はどこに保存しますか？
- パスワードリセット機能は必要ですか？

勝手に実装を進めるのではなく、**重要な決定は人間に委ねる**設計思想により、意図と異なる実装が生まれにくくなっています。

## 使い分けの指針

すべてのタスクをClaude Codeに任せれば良いわけではありません。

**Claude Codeに適したタスク**:
- 新機能の実装
- 複数ファイルにまたがる修正
- リファクタリング
- バグ修正と検証

**手動の方が速いタスク**:
- 単純なタイプミスの修正
- 1行だけの変更
- 既知の軽微な修正

タスクの規模や複雑さに応じて使い分けることが重要です。
