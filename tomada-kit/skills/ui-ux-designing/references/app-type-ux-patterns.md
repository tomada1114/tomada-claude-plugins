# アプリタイプ別UXパターン

アプリのタイプごとのUXベストプラクティスと避けるべきパターン。

---

## 会話/音声アプリ

### 参考アプリ

- **Speak** - AI英会話練習
- **Duolingo** - 言語学習（チャットボット機能）
- **ELSA Speak** - 発音練習
- **ChatGPT App** - 音声入力対応AI

### ベストプラクティス

#### 会話中UI

```
推奨: ミニマルUI
- 波形アニメーションで状態を表示
- テキスト表示は最小限（または非表示）
- 会話に集中させる

避ける:
- 大量のテキスト表示
- 複数のアクションボタン
- 進捗バーなどの気を散らす要素
```

#### フィードバック

```
推奨: セッション後にまとめて
- 会話終了後に詳細フィードバック
- スコア + 改善提案の組み合わせ

避ける:
- 会話中の頻繁な中断
- リアルタイムの評価表示（プレッシャーになる）
```

#### 音声状態の視覚化

```
推奨:
- AI発話中: 波形がアクティブ（アクセントカラー）
- ユーザー発話中: 波形がアクティブ（別色）
- 待機中: 波形が静止

避ける:
- 状態が不明確なUI
- テキストのみの状態表示
```

### 避けるべきパターン

| パターン | 問題点 | 代替案 |
|---------|--------|--------|
| 毎回質問で終わる | 尋問のように感じる | 自然な会話の流れを維持 |
| 即時フィードバック | プレッシャーになる | セッション後にまとめて |
| 複雑な設定画面 | 使う前に疲れる | デフォルト値を最適化 |

## Eコマース/ショッピング

### 参考アプリ

- **Amazon** - 総合EC
- **Shopify** - EC基盤
- **SHEIN** - ファッションEC

### ベストプラクティス

#### 商品リスト

```
推奨:
- 大きな商品画像
- 価格を目立たせる
- レビュースコアを表示
- 無限スクロール or ページネーション

避ける:
- 小さすぎる画像
- 情報過多のカード
- 遅いローディング
```

#### 商品詳細

```
推奨:
- 画像ギャラリー（スワイプ可能）
- 段階的情報開示（基本→詳細→レビュー）
- 固定CTAボタン（カートに追加）

避ける:
- 1ページに全情報
- スクロールしないとCTAが見えない
```

#### カート/チェックアウト

```
推奨:
- ステップインジケーター
- 入力の自動補完
- 明確なエラー表示

避ける:
- 長すぎるフォーム
- 不要な情報の要求
- 戻るボタンの欠如
```

### 避けるべきパターン

| パターン | 問題点 | 代替案 |
|---------|--------|--------|
| ポップアップ多用 | ユーザーを邪魔 | 控えめなバナー |
| 強制会員登録 | 離脱率上昇 | ゲスト購入許可 |
| 隠れた送料 | 信頼低下 | 事前に明示 |

## ダッシュボード/管理画面

### 参考アプリ

- **Notion** - ワークスペース
- **Linear** - プロジェクト管理
- **Vercel** - デプロイ管理

### ベストプラクティス

#### レイアウト

```
推奨:
- 左サイドバー（ナビゲーション）
- 上部にKPI/重要指標
- カード形式のセクション

避ける:
- 複雑すぎるナビゲーション
- 情報の詰め込みすぎ
- 一貫性のないレイアウト
```

#### データ表示

```
推奨:
- 概要 → 詳細のドリルダウン
- フィルタリング/ソート機能
- データのエクスポート

避ける:
- 全データを一度に表示
- ページネーションなしの長いリスト
- 検索機能の欠如
```

#### アクション

```
推奨:
- 明確なプライマリアクション
- 確認ダイアログ（破壊的操作）
- アンドゥ機能

避ける:
- 曖昧なボタンラベル
- 確認なしの削除
- 深すぎる階層
```

### 避けるべきパターン

| パターン | 問題点 | 代替案 |
|---------|--------|--------|
| 情報過多 | 認知負荷が高い | 段階的開示 |
| 深い階層 | 迷子になる | フラットな構造 |
| 統一性なし | 学習コスト高い | デザインシステム |

## SNS/コミュニティ

### 参考アプリ

- **Twitter/X** - マイクロブログ
- **Instagram** - 写真共有
- **Discord** - コミュニティチャット

### ベストプラクティス

#### フィード

```
推奨:
- 無限スクロール
- プルトゥリフレッシュ
- エンゲージメントボタン（いいね、シェア）

避ける:
- 遅いローディング
- 広告の乱用
- 自動再生動画（音あり）
```

#### プロフィール

```
推奨:
- アバター + 基本情報
- タブでコンテンツ分類
- フォロー/フォロワー数

避ける:
- 編集しにくいプロフィール
- 過度な情報要求
```

#### 通知

```
推奨:
- カテゴリ分け
- 既読/未読の明確化
- 通知設定のカスタマイズ

避ける:
- 通知の乱発
- 設定変更の困難さ
```

### 避けるべきパターン

| パターン | 問題点 | 代替案 |
|---------|--------|--------|
| ダークパターン | 信頼低下 | 透明性確保 |
| 強制的な通知 | ユーザー離れ | オプトイン |
| 複雑な設定 | 使いこなせない | シンプルなデフォルト |

## 学習/教育アプリ

### 参考アプリ

- **Duolingo** - 言語学習
- **Khan Academy** - 総合教育
- **Coursera** - オンラインコース

### ベストプラクティス

#### 進捗表示

```
推奨:
- 明確なゴール表示
- 進捗バー/パーセンテージ
- ストリーク（連続学習）表示

避ける:
- 進捗が見えない
- 達成感のない設計
```

#### レッスン構造

```
推奨:
- 短いユニット（5-15分）
- 復習の組み込み
- 難易度の段階的上昇

避ける:
- 長すぎるセッション
- 復習機能の欠如
- 急激な難易度上昇
```

#### モチベーション

```
推奨:
- ゲーミフィケーション（適度に）
- 達成バッジ
- リマインダー機能

避ける:
- 過度なゲーミフィケーション
- 罰則的な設計
- プレッシャーを与えすぎ
```

### 避けるべきパターン

| パターン | 問題点 | 代替案 |
|---------|--------|--------|
| 長すぎるセッション | 集中力低下 | 短いユニット |
| 失敗の強調 | やる気低下 | 成長の強調 |
| 一方的な講義 | 退屈 | インタラクティブ |
