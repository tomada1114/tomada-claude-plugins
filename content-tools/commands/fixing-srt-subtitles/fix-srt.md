# Fix SRT Transcription

SRTファイルの誤変換と不自然な改行位置を修正します。

**引数:**
- `$1`: ディレクトリパス（必須）- SRTファイルと参照用Markdownファイルを含むディレクトリ

---

## Step 1: Validate Directory and Detect Files

### ディレクトリの確認

1. **ディレクトリ存在確認**: `$1`
   - ディレクトリが存在することを確認

**ディレクトリが存在しない場合:**
```
❌ ディレクトリが見つかりません: $1
処理を中止します。
```

### SRTファイルの自動検出

1. `$1` ディレクトリ内の `.srt` ファイルを検索
2. 検出結果に応じて処理:

| 検出数 | 処理 |
|--------|------|
| 0個 | エラー終了 |
| 1個 | そのファイルを使用 |
| 2個以上 | エラー終了（特定不可） |

**SRTファイルがない場合:**
```
❌ SRTファイルが見つかりません: $1
処理を中止します。
```

**SRTファイルが複数ある場合:**
```
❌ SRTファイルが複数見つかりました: $1
1つのみにするか、ファイルパスを直接指定してください。
処理を中止します。
```

### 参照ファイルの自動検出（任意）

1. `$1` ディレクトリ内の `*.md` ファイルを全て検索
2. 見つかった全てのMarkdownファイルを参照ファイルとして使用
3. Markdownファイルがない場合は警告を表示して続行

**参照ファイルがない場合:**
```
⚠️ 参照用Markdownファイルが見つかりません
誤変換辞書のみで修正を続行します。
```

---

## Step 2: Read Files

以下のファイルを読み込んでください：

1. **SRTファイル**: Step 1で検出したSRTファイル
   - 修正対象

2. **参照ファイル**: Step 1で検出した全Markdownファイル
   - 正確な用語・表記を把握するために使用
   - 複数ある場合は全て読み込む

---

## Step 3: Invoke fixing-srt-subtitles Skill

`fixing-srt-subtitles` スキルの知識を活用して修正を行います。

### 修正の優先順位

1. **用語の誤変換**（参照ファイルと照合）
   - 参照ファイルに出現する専門用語・固有名詞を正確な表記に
   - Claude Code → クロードコード などの誤変換を修正

2. **単語の分断**
   - 「ファイ」+「ル」→「ファイル」を前後の字幕間で調整
   - タイムコードは変更しない

3. **改行位置の最適化**
   - 助詞・句読点の後で区切る
   - 複合語を分断しない
   - **助詞（の、が、を、に、で、は、と、も）が行頭に来ないように**

4. **行末句読点の削除**
   - 字幕の行末に「、」「。」は不要

### 参照ファイル照合のポイント

参照ファイルから以下を抽出して照合に使用：
- **固有名詞**: Claude Code, CLAUDE.md, TypeScript など
- **コマンド**: /memory, /context など
- **ファイル名**: *.md, *.ts など
- **専門用語**: AI駆動開発, バイブコーディング など

---

## Step 4: Apply Fixes (誤変換・改行位置)

SRTファイルの誤変換と改行位置を修正してください。

### 修正ルール

1. **タイムコード・字幕番号は変更しない**（この段階では）
2. **テキストの区切り位置は調整OK**（前後の字幕間でテキスト移動）
3. **1行ごとの字幕が自然に完結すること**

### 修正例

**Before:**
```srt
15
00:00:32,400 --> 00:00:35,880
クロードコードではcloud.mdというファイ

16
00:00:35,880 --> 00:00:38,520
ルに開発ルールを書くことができます
```

**After:**
```srt
15
00:00:32,400 --> 00:00:35,880
Claude CodeではCLAUDE.mdという

16
00:00:35,880 --> 00:00:38,520
ファイルに開発ルールを書くことができます
```

## Step 5: Split Long Subtitles (長文字幕分割) - 必須

24文字を超える字幕を検出し、**すべて24文字以下になるまで反復分割**します。

### 5.1 反復分割ループ

以下のループを**全ての字幕が24文字以下になるまで**繰り返す：

```
iteration = 1
WHILE 24文字超の字幕が存在:
    1. detect_long_subtitles.py で検出
    2. srt-splitter サブエージェントに分割提案を依頼
    3. 提案をもとにSRTファイルを修正
    4. タイムコードを文字数比で按分
    5. 字幕番号を再採番
    6. iteration++
    7. 最大5回で強制終了（無限ループ防止）
END WHILE
```

### 5.2 検出スクリプト実行

```bash
python ~/.claude/skills/fixing-srt-subtitles/scripts/detect_long_subtitles.py <SRTファイルパス> --max-chars 24
```

※ `<SRTファイルパス>` はStep 1で検出したSRTファイルのフルパス

### 5.3 分割提案と適用

1. **srt-splitter サブエージェントに分割提案を依頼**
   - Taskツールで `srt-splitter` を呼び出し
   - 検出された**全ての**長文字幕の分割を提案させる

2. **メインエージェントが修正を適用**
   - 提案をもとにSRTファイルを修正
   - タイムコードを文字数比で按分
   - 字幕番号を再採番

### タイムコード按分の計算

```
例: 00:10:56,000 --> 00:11:01,000 (5秒)
    17文字 + 11文字 + 11文字 = 39文字

    1つ目: 17/39 × 5秒 → 00:10:56,000 --> 00:10:58,179
    2つ目: 11/39 × 5秒 → 00:10:58,179 --> 00:10:59,589
    3つ目: 11/39 × 5秒 → 00:10:59,589 --> 00:11:01,000
```

### 5.4 再検出と反復

分割適用後、再度検出スクリプトを実行：
- 24文字超の字幕が残っている場合 → 5.2に戻る
- すべて24文字以下になった場合 → Step 6へ進む

### 5.5 完了条件（ゼロ許容ルール）

**重要**: 24文字超の字幕は1つも残してはいけない。

- **成功**: 全ての字幕が24文字以下になった → Step 6へ進む
- **失敗**: 5回の反復後も24文字超が残っている → エラーレポートを出力

```
❌ エラー: 24文字超の字幕が残っています（ゼロ許容ルール違反）

残存する長文字幕:
- 番号XX: 「テキスト」(YY文字)

手動で確認・修正してください。
```
