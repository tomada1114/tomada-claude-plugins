# Generate Video Script

ソースファイルから台本を生成し、指定ディレクトリに保存します。

**引数:**
- `$1`: 素材ファイルパス（必須）- Markdown記事、メモなど
- `$2`: 出力先ディレクトリ（必須）

**出力:**
- `{output_dir}/{slug}.md` - slug は内容から自動生成

---

## Step 1: Validate Arguments

引数を検証してください。

### 必須チェック:
- `$1` (source_file): 存在しない場合はエラー
- `$2` (output_dir): 存在しない場合は作成

### エラー時:
```
❌ エラー: 引数が不足しています

使用方法: /video-script-writing:generate <source_file> <output_dir>

例: /video-script-writing:generate ./article.md ./scripts
```

---

## Step 2: Read Source File

`$1` で指定されたソースファイルを読み込んでください。

### 対応形式:
- `*.md` ファイル（Markdown）
- `*.txt` ファイル（テキスト）

### ファイルが読めない場合:
```
❌ エラー: ファイルが読み込めません: {$1}

ファイルパスを確認してください。
```

---

## Step 3: Clarify Requirements

**CRITICAL**: AskUserQuestion ツールを使って以下を確認してください。

### 3.1 動画タイプ
質問: 「この動画はどのタイプですか？」
選択肢:
- 新機能紹介 (推奨) - 新しいツール/機能を紹介
- ツール紹介 - 既存ツールの使い方
- 概念解説 - 技術概念やノウハウ
- チュートリアル - ハンズオン形式
- 比較 - 複数ツール/アプローチの比較

### 3.2 想定尺
質問: 「想定している動画の長さは？」
選択肢:
- 5分（短尺、ポイント絞って）
- 10分（標準、1つのトピックを深く）(推奨)
- 15分（詳細、複数セクション）
- 20分以上（長尺、包括的）

### 3.3 対象者レベル
質問: 「視聴者のレベルは？」
選択肢:
- 初心者（用語説明を丁寧に）
- 中級者（基本は省略、応用に集中）(推奨)
- 上級者（専門的な内容、高度なTips）

### 3.4 特に強調したいポイント（任意）
質問: 「特に強調したいポイントはありますか？」
選択肢:
- 特になし（記事の構成に従う）(推奨)
- ある（自由入力で記載）

---

## Step 4: Invoke video-script-writing Skill

`video-script-writing` スキルを使用して台本を生成してください。

### スキルへの入力情報:
1. **ソースファイルの内容**: Step 2で読み込んだ内容
2. **動画タイプ**: Step 3.1の回答
3. **想定尺**: Step 3.2の回答
4. **対象者レベル**: Step 3.3の回答
5. **強調ポイント**: Step 3.4の回答（ある場合）

### 生成ルール:
- **挨拶なし** - いきなり本題に入る
- **1文40字以内** を意識
- **語尾を多様に** - ですね、になります、でしょう など
- **リスク言及** を含める
- **CTA** を締めに含める
- **NGワード禁止** - ヤバい、神、最強、絶対、簡単 など

---

## Step 5: Generate Slug

ソースファイルの内容からslugを自動生成してください。

### 生成ルール:
1. タイトル・主要キーワードを抽出
2. 英語のスネークケースに変換
3. 簡潔に（3-5語程度）

### 例:
- 記事「Claude Codeの動的ルール機能」→ `claude_code_dynamic_rules`
- 記事「MCPサーバー入門」→ `mcp_server_basics`
- 記事「Gemini 2.0 Flash画像生成」→ `gemini_2_flash_image_gen`

---

## Step 6: Automated Evaluation

**CRITICAL**: 台本生成後、自動評価を実行してください。

### 評価基準（7軸100点満点）

| 軸 | 配点 | 閾値 | チェック内容 |
|----|------|------|-------------|
| Structure | 20pt | 16pt | 冒頭-本編-締めの3部構成 |
| Speech Pattern | 20pt | 16pt | 語尾パターン3種類以上、親近感表現2個以上 |
| Engagement | 15pt | 12pt | 問いかけ2回以上、包含表現3回以上 |
| Technical Accuracy | 15pt | 12pt | リスク言及あり |
| Readability | 15pt | 12pt | 短文率80%以上（1文40字以内） |
| NG Word | 10pt | 10pt | **NGワード0件必須** |
| CTA | 5pt | 4pt | チャンネル登録・高評価の呼びかけ |

### 合否判定:
- **合格**: 総合90点以上 + 全軸が閾値以上
- **不合格**: 改善して再評価（最大3回）

## Step 7: Save Script

台本を保存してください。

### 保存先:
```

```

### 保存形式:
```markdown

- 想定尺: XX分
- 文字数: X,XXX字
- 対象: [初心者/中級者/上級者]
- 評価スコア: XX/100

---

## 冒頭（0:00-X:XX）

[台本本文]

---

## 本編

### セクション1: [トピック]（X:XX-X:XX）

[台本本文]

---

## 締め（X:XX-X:XX）

[台本本文]
```
