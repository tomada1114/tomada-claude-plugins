## 推奨される日本語表現

### 技術用語の日本語化

✅ **推奨（日本語+英語の併記）**:
```
リポジトリ（repository）
コミット（commit）
ブランチ（branch）
```

✅ **推奨（日本語の補足説明）**:
```
Gitは、変更履歴を記録してくれるツール（バージョン管理システム）です。
```

❌ **避けるべき（英語のみ）**:
```
distributed version control system
```

### 技術的に正確だが親しみやすい表現

✅ **推奨**:
- 「変更を記録する」（コミット）
- 「過去の状態に戻す」（ロールバック）
- 「並行して開発する」（ブランチ）

❌ **避けるべき（専門用語の羅列）**:
- 「distributed version control systemでcommitしてpush」

## 初心者向け用語の説明パターン

### パターン1: 日本語→英語→補足
```
コミット（commit）とは、変更を記録する操作です。
```

### パターン2: 比喩→正式名称→説明
```
まるでゲームのセーブポイントのように、Gitでは重要な変更の前にコミット（記録）しておくことができます。
```

### パターン3: 行為→技術用語
```
変更を記録することを、Gitでは「コミット」と呼びます。
```

---

## 避けるべき専門用語の使い方

❌ **悪い例（説明なしの専門用語）**:
```
リモートリポジトリにpushしてupstreamをtrackしましょう。
```

✅ **改善**:
```
ローカル（自分のパソコン）で作った変更を、リモートリポジトリ（GitHub等のサーバー）に送信（push）しましょう。
```
