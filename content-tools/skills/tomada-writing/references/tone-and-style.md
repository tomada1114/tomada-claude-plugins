# とまだ式文体ガイド

**Version**: 1.1.0
**Last Updated**: 2025-12-31

このドキュメントは、とまだ式の執筆ガイドラインです。

---

## とまだ式文体の考え方

> **「大学の先生が研究室で雑談するような親しみやすさ」と「論文を引用する学術的信頼性」の両立**

---

## とまだ式の6つの柱

### 1. 控えめな断定（誠実さ）

| 避ける表現 | 使う表現 |
|-----------|---------|
| 「〜です」（断定） | 「〜ではないでしょうか」 |
| 「絶対に〜」 | 「〜と考えています」 |
| 「必ず〜」 | 「〜かもしれません」 |
| | 「〜こともあります」 |

**ポイント**: 「私は〜と考えています」で意見を述べつつ、論文やベンチマークで裏付けを示す。

### 2. 両面提示（信頼感）

- 「一方で」「ただ」「とはいえ」を積極的に使用
- メリットだけでなくデメリットも正直に伝える
- 「神プロンプト」的な煽りへの距離感を示す

**例**:
```
〇〇は便利ですが、一方で△△には向かない場合もあります。
ただ、〜という限界もあります。
とはいえ、〜というリスクも存在します。
```

### 3. 読者の疑問を先回り（オプション）

読者が「〜では？」と思いそうな疑問を先に拾って答える。**使用は任意**です。

**例**（自然な場合のみ使用）:
```
「『〇〇では？』と思った方もいるかもしれません」
「ここまで聞いて『△△と何が違うの？』と思った方もいるかもしれません」
「『え、これ全部やらなきゃいけないの…？』と怯まれた方、ご安心ください」
```

**注意**: 無理に入れると文章が回りくどくなる場合があります。

### 4. 括弧による補足・本音

補足説明や本音を括弧で挿入する。

**例**:
```
（これは揶揄する意図ではなく、事実としてそういうものも存在するという話です）
（正直私もまだ模索中ですが）
（ちなみにこの用途では〇〇が推しです）
```

### 5. カジュアルな口語表現

適度なカジュアルさで親しみやすさを出す。

| パターン | 例 |
|---------|-----|
| 柔らかい副詞 | 中々、なんとな〜く、ちょっと |
| くだけた表現 | めっちゃ、まあまあ、シュッと |
| 感嘆・感情 | もうワクワクですね、お、おう |
| 擬態語 | ガラッと、グッと、ペタペタ |

**注意**: 使いすぎない。適度に。

### 6. 論文・公式ドキュメントによる裏付け

信頼感を生むために、論文やベンチマーク結果を引用する。

**例**:
```markdown
研究では、〇〇という現象が観察されています。詳しくは以前の動画で解説していますが、簡単に言うと△△という現象です。

[論文タイトル](URL)
```

## とまだ式の全体構造

**導入 → 結論先出し → 詳細解説 → 余談 → 締め**

```
1. 問題提起・読者の悩みに共感
2. 「今回伝えたいことの要点は〜」と結論を先に
3. 詳細をセクション分けで丁寧に解説
4. 「余談」で知的好奇心を満たす追加コンテンツ
5. 「以上」「それでは」で締め
```

## 接続詞・文末表現

### よく使う接続詞

| 接続詞 | 用途 |
|-------|-----|
| というわけで | 結論への導入 |
| ただ、一方で | 両面提示 |
| なので | 因果関係 |
| では | セクション切り替え |
| そこで | 解決策の提示 |

### 文末表現

```
「〜と思います」「〜と考えています」（個人見解の明示）
「〜ではないでしょうか」（柔らかい提案）
「〜していきましょう」（読者への呼びかけ）
「〜かもしれません」（可能性の示唆）
```

### 締めの定型

```
「以上、〇〇についての解説でした」
「本記事が〜のきっかけになれば幸いです」
「それでは、また次回の記事・動画で！」
```

## 実装チェックリスト

記事を書く際、以下を確認:

**必須**:
- [ ] 挨拶の後に「結論先出し」があるか
- [ ] 「一方で」「ただ」で両面提示しているか
- [ ] 括弧で補足・本音を入れているか（適度に）
- [ ] 断定的な表現を避けているか
- [ ] 「大丈夫です」を多用していないか（事実ベースで安心感）
- [ ] 論文・公式ドキュメントで裏付けがあるか（該当する場合）

**参考**（評価対象外・任意で追加可）:
- 共感的問いかけ（「〜で困っていませんか？」）
- 読者の疑問を先回り（「〜と思った方もいるかもしれません」）
