# 検証レポート型テンプレート

**重さ**: 重め（週1本程度）
**文字数目安**: 2000-4000字
**用途**: 新機能を使い込んでからの感想・検証結果
**評価基準**: 95点以上

---

## テンプレート構造

```markdown
こんにちは、とまだです。

【結論先出し】
○○を【期間】使い込んでみた結論を先に言うと、△△という印象です。

（正直まだ使い始めたばかりの部分もありますが、現時点での感想をまとめます）

## 忙しい人のために要約

- **良かった**: ○○
- **微妙だった**: △△
- **向いている人**: □□
- **向いていない人**: ××

## 検証環境・条件

| 項目 | 内容 |
|-----|------|
| 期間 | ○日間 |
| 用途 | △△ |
| 環境 | □□ |
| バージョン | ×× |

## 良かった点

### 1. ○○

【具体的な説明】

【コード・スクリーンショット】

### 2. △△

【具体的な説明】

### 3. □□

【具体的な説明】

## 限界・注意点

一方で、以下のような限界も感じました。

### 1. ○○

【具体的な説明】

（「○○と思った方もいるかもしれませんが」のような疑問先回り）

### 2. △△

【具体的な説明】

## 実際の使用例

ここでは、実際に私が使った例を紹介します。

【コード・スクリーンショット・具体的な使用シーン】

## 結論と個人的な評価

【事実ベースの本音】

私は〇〇と考えています。

（正直私もまだ模索中ですが...のような括弧補足）

【どういう人におすすめか】

【どういう人には合わないか】

## 参考リンク

- [公式ドキュメント](URL)
- [関連記事](URL)
```

---

## 必須要素チェックリスト

- [ ] 冒頭に「こんにちは、とまだです」
- [ ] 結論先出し（使い込んだ結果の一言評価）
- [ ] 検証環境・条件の明記
- [ ] 良かった点（具体的に3つ程度）
- [ ] 限界・注意点（両面提示）
- [ ] 実際の使用例（コード・スクリーンショット）
- [ ] 事実ベースの個人的評価

---

## とまだ式チェックリスト

- [ ] 「一方で」「ただ」で限界も正直に伝えているか
- [ ] 「〜と考えています」「〜ではないでしょうか」を使っているか
- [ ] 括弧で本音を入れているか（「正直まだ〜」）
- [ ] 読者の疑問を先回りしているか
- [ ] 公式ドキュメントへの参照があるか

---

## このテンプレートを使う場面

- 新機能を1週間以上使い込んだ後の評価
- アップデート後の検証レポート
- 「○○を使ってみた」系の記事
- 競合ツールとの比較前の単体評価
