## 必須要素チェックリスト

- [ ] 冒頭に「こんにちは、とまだです」
- [ ] 読者の疑問先回り（「○○と感じていませんか？」）
- [ ] 結論先出し（問いかけ直後に結論）
- [ ] 「忙しい人のために要約」セクション
- [ ] ステップバイステップ構成（5-7ステップが理想）
- [ ] コード例が実行可能な状態
- [ ] よくあるエラーと対処（両面提示）
- [ ] まとめで結論を再確認

---

## とまだ式チェックリスト

- [ ] 「一方で」「ただ」で限界も正直に伝えているか
- [ ] 断定を避けて「〜と考えています」「〜ではないでしょうか」を使っているか
- [ ] 括弧で補足・本音を入れているか
- [ ] 公式ドキュメントへの参照があるか
