# 比較分析型テンプレート

**重さ**: 中程度（週1-2本）
**文字数目安**: 1500-3000字
**用途**: 機能A vs 機能B、Claude Code vs 他ツールの比較
**評価基準**: 95点以上

---

## 必須要素チェックリスト

- [ ] 冒頭に「こんにちは、とまだです」
- [ ] 結論先出し（どちらがおすすめか）
- [ ] 比較表（一目で違いがわかる）
- [ ] 各項目の強み・弱み（両面提示）

---

## とまだ式チェックリスト

- [ ] 「一方で」「ただ」で両面提示しているか
- [ ] 「〜と考えています」を使っているか
- [ ] 括弧で補足を入れているか
- [ ] 特定の選択肢を過度に推さない（両面提示）
- [ ] 公式ドキュメントへの参照があるか
