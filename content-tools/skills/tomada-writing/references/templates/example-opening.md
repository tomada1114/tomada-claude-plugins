# 冒頭構成の例（example-opening）

冒頭に必要な要素とその順序を示すお手本です。
自動挿入はされません。参照して手動で記事に追加してください。

---

## 冒頭の必須要素（4つ）

1. **挨拶** - 「こんにちは、とまだです。」
2. **結論先出し** - 「今回伝えたいことの要点は〇〇です」
3. **価値提示** - 「この記事を読むと〇〇できるようになります」
4. **要約セクション** - 忙しい人向けの箇条書き要約

---

## 例文

```markdown
こんにちは、とまだです。

今回伝えたいことの要点は、**サブエージェントは3つのファイルを作るだけで動く**ということです。

この記事では、Claude Codeのサブエージェント機能について解説します。読み終わる頃には、自分専用のサブエージェントを作成できるようになります。

## 忙しい人のために要約

- サブエージェントは `.claude/agents/` に YAML+Markdown で定義
- 必須項目は `name`, `description`, `tools` の3つだけ
- 「PROACTIVELY」を description に含めると自動起動
- 起動確認は `/agents` コマンドで可能
```

---

## チェックリスト

記事を書き始める前に、以下を確認してください：

- [ ] 挨拶が最初の200文字以内にあるか
- [ ] 「今回伝えたいこと」「要点は」などの結論先出しがあるか
- [ ] 「この記事では〜を解説」「読み終わる頃には〜できる」などの価値提示があるか
- [ ] 「## 忙しい人のために要約」セクションがあるか

---

## 補足：各要素の詳細

### 1. 挨拶（必須）
```
こんにちは、とまだです。
```
- 必ず最初の200文字以内に配置
- シンプルに、一貫した形式で

### 2. 結論先出し（必須）
```
今回伝えたいことの要点は、〇〇ということです。
一言で言えば、〇〇です。
結論から言うと、〇〇です。
```
- 記事全体の結論を最初に述べる
- 読者が「読む価値があるか」を判断できる

### 3. 価値提示（必須）
```
この記事では〇〇を解説します。
読み終わる頃には、〇〇できるようになります。
〇〇が身につきます。
```
- 読者が得られるメリットを明示
- 具体的なゴールを示す

### 4. 要約セクション（必須）
```
## 忙しい人のために要約

- ポイント1
- ポイント2
- ポイント3
```
- 3〜5個の箇条書き
- 記事全体の要点を凝縮
