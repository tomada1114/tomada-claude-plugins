# note.com Markdown制約

note.comは標準Markdownの一部をサポートしていません。記事執筆時は必ずこの制約に従ってください。

---

## 使えないMarkdown構文

| 構文 | 変換方法 |
|------|----------|
| テーブル | 箇条書きに展開 |
| H4-H6見出し（####〜######） | 太字（**text**）に変換 |
| 打ち消し線（~~text~~） | （text）括弧表記に変換 |
| タスクリスト（- [ ] / - [x]） | ・[未] / ・[済]に変換 |
| 脚注（[^N]） | インライン注釈に展開 |
| HTMLタグ | 削除 |
| 水平線（---） | 削除（空行で代替） |
| Markdownリンク（[title](url)） | URLのみに変換 |
| ローカル画像パス | 外部ホスティング必須 |

---

## 変換例

### テーブル → 箇条書き

```markdown
<!-- ❌ 使えない -->
| 項目 | 値 |
|------|-----|
| A    | 100 |

<!-- ✅ 箇条書きに展開 -->
- **項目**: A, **値**: 100
```

### H4以下 → 太字

```markdown
<!-- ❌ 使えない -->
#### 小見出し

<!-- ✅ 太字に変換 -->
**小見出し**
```

### 打ち消し線 → 括弧

```markdown
<!-- ❌ 使えない -->
~~削除されたテキスト~~

<!-- ✅ 括弧に変換 -->
（削除されたテキスト）
```

### タスクリスト → 代替表記

```markdown
<!-- ❌ 使えない -->
- [ ] 未完了
- [x] 完了

<!-- ✅ 代替表記 -->
・[未] 未完了
・[済] 完了
```

### 脚注 → インライン注釈

```markdown
<!-- ❌ 使えない -->
本文[^1]です。
[^1]: 脚注説明

<!-- ✅ インライン化 -->
本文（※注1: 脚注説明）です。
```

### Markdownリンク → URL直接表示

```markdown
<!-- ❌ 使えない -->
[Zenn](https://zenn.dev)

<!-- ✅ URLのみ -->
https://zenn.dev
```

## 使えるMarkdown構文

以下はnoteでも使用可能:

- **H1-H3見出し**（#, ##, ###）
- **太字**（**text**）
- **斜体**（*text*）
- **箇条書き**（- または *）
- **番号付きリスト**（1. 2. 3.）
- **引用**（>）
- **コードブロック**（```）
- **インラインコード**（`code`）
- **画像**（外部URLのみ）

---

## AI Assistant Instructions

note記事を執筆する際は:

1. **テーブルを使わない**: 箇条書きで表現
2. **見出しはH3まで**: H4以下は太字に
3. **リンクはURL直接表示**: [title](url)形式を避ける
4. **水平線を使わない**: 空行で区切りを表現
5. **画像は外部ホスティング**: Gyazo等のURLを使用

執筆完了後、これらの制約に違反していないか必ず確認すること。
