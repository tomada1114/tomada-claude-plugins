# Udemy講座宣伝テンプレート

## 適用条件

以下のトピックに関連する記事を執筆・公開する場合、記事末尾にこのテンプレートを追加すること。

**対象トピック:**
- Claude Code全般
- CLAUDE.md
- .claude/rules/（動的ルール）
- カスタムコマンド
- サブエージェント
- Skills
- Hooks

**適用除外:**
- MCP関連（別講座）
- Claude API / Anthropic SDK（別講座）
- Claude Code以外のAIツール

## 使用方法

1. 記事のトピックが対象かどうかを確認
2. 対象の場合、記事の「まとめ」セクションの後にテンプレートを追加
3. 他の「関連記事」「次に読むべき記事」セクションがある場合は、その後に配置

## 配置順序の例

```markdown
## まとめ

（まとめ内容）

## 関連記事（あれば）

（関連記事リンク）

## 📚 Udemy講座でさらに詳しく学ぶ  ← ここに追加

（テンプレート内容）
```
